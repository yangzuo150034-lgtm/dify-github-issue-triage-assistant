# Privacy Policy

Last updated: October 13, 2026

GitHub Issue AI Triage Assistant makes read-only HTTPS requests to the GitHub REST API using a credential supplied by the Dify workspace administrator.

The plugin processes the repository owner, repository name, issue filter settings, and public issue data needed to produce its output. It does not intentionally collect or store credentials, analytics, or user profiles. The GitHub token is sent only to GitHub for authentication and is never included in tool output.

Issue content returned by the plugin is passed to the Dify application and may be processed by the model provider configured for the Workflow. Users should review the privacy policies of Dify, GitHub, and their selected model provider.

The plugin does not sell personal information. Remove the plugin credential from Dify and revoke the GitHub token to end access.
